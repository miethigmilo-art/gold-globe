# 🤖 AI Crawler – AI-Layer für Websites

## Kernidee
Ein Tool/Service das Websites eine zusätzliche Ebene hinzufügt, die von AI-Agents effizient gelesen und genutzt werden kann.

> **These:** Die nächste Milliarde Internetnutzer werden keine Menschen sein, sondern AI-Agents — Websites müssen sich darauf vorbereiten.

---

## Marktlage
- Standard `llms.txt` existiert bereits, ist aber noch sehr nischig
- **GEO (Generative Engine Optimization)** ist der aufkommende Begriff für AI-Sichtbarkeit
- **Firecrawl** ist der relevanteste Player — löst das Problem aber von der Agent-Seite, nicht von der Website-Seite
- Die **"Website-Besitzer-Seite" ist noch komplett unbesetzt** → das ist die Lücke

---

## Das Produkt (zwei Ebenen)

### 1) AI-Layer Tool
- Crawlt automatisch eine Website
- Generiert sauberes Markdown + strukturierte Daten
- Legt einen separaten AI-lesbaren Endpoint drüber
- Ohne die echte Website anzufassen

### 2) Verzeichnis (Registry)
- Registry von AI-optimierten Websites, die Agents aktiv nutzen können
- Hat **Network-Effect-Potenzial**
- Monetarisierbar durch:
  - Subscriptions
  - Featured Listings
  - Analytics-Dashboard
  - API-Zugang für Entwickler

---

## Geschäftsmodell
- Firmen zahlen monatlich für Listing + aktiven AI-Layer
- Analytics verkaufen ("deine Website wurde diese Woche von X Agents aufgerufen")
- API-Zugang für AI-Entwickler

---

## Größtes offenes Problem
Wie erfahren Agents von der optimierten Website? Aktuell kein zentraler Index — das **Verzeichnis wäre die eigene Antwort** darauf.
